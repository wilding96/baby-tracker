# POP3D 首玩反馈（模拟评测）

日期：2026-10-20
版本：`05db370`（短局循环 + 开局弹幕加密 + 朝向修正之后）
对象：`src/app/game/pop3d/`

> **说明**：这不是真人试玩记录，而是按"有十年弹幕游戏经验、同时玩过手游割草"的玩家视角，
> 对照当前代码、实测跑局数据做的推演型评测。所有数值都来自仓库内的配置与无头跑局。

---

## 0. 评测人设定

- 打过《雷电》《怒首领蜂》《东方》和 Cave 系弹幕，熟悉"小判定 + 低速 + 擦弹"这套语言
- 手机竖屏短局能接受，但不接受"手感发黏"和"看不清判定"
- 判断一个弹幕游戏好不好，先看三件事：**躲得准不准、弹幕读不读得清、Boss 记不记得住**

## 1. 总评

> "结构对了，节奏也对了，但现在更像一个做对了结构的原型。前 20 秒偏温，Boss 没有记忆点，
> 手感上有两处硬伤。"

值得肯定的部分：

- 100 秒一局、60 秒见 Boss，手机上的时长正确
- 一局固定 3 次三选一，不打断战斗
- Boss 转阶段清屏 + 停帧 + 运镜，爽点成立
- 海克斯卡面的方向对了
- 自动开火 + 拖拽移动，适合移动端

## 2. 首玩时间线

| 时间 | 场上情况 | 老手的第一反应 |
| --- | --- | --- |
| 0–10s | 1–2 架无人机，约 3 发弹 | "是不是还没开始？" |
| 10–20s | 无人机三连，弹幕 3–5 颗 | 比之前好，但仍是热身 |
| 20s | 第一次三选一 | 卡能读，但不知道哪个强 |
| 20–38s | 炮台加入，弹幕 5–14 颗 | 开始有点意思 |
| 38–58s | 编织机成排，弹幕 20–60 颗 | "第一堵墙，而且没有预告" |
| 58–60s | 第三张卡 + Boss 预警 | 节奏对 |
| 60s+ | Boss 三阶段 | 爽，但招式眼熟 |
| 结算 | 档位 +1 | "局内完全没感觉到" |

## 4. 反馈与 TODO

优先级说明：

- **P0**：首玩就会影响手感或留存，建议下一轮全部处理
- **P1**：影响"愿不愿意再开一局"，P0 之后处理
- **P2**：打磨项，随版本迭代

> **进度（2026-10-20）**：P0-1 ~ P0-4 已全部实现，验收项见下方勾选。

### P0-1 判定点 + 低速模式

**问题**：贴图 5.4 单位、判定半径 1.0，视觉上完全看不出判定在哪。老手会按翅膀边缘躲，
结果中弹；或者以为自己要死却没死。没有低速模式，密集弹幕下无法做精细位移。

**改法**

- 玩家机中心画一个 2–3px 的白芯点（带 1px 墨边），只在 `playing` 时显示
- 增加低速：键盘 `Shift` / 触屏长按，移动速度与跟随系数降到 0.5×
- 低速时不改变判定半径，只降低位移速度

**涉及文件**：`render/paper.ts`、`engine/game.ts`、`engine/config.ts`

**验收**

- [x] 判定点在任何渲染器下都可见（至少 paper 必做）
- [x] 低速可键盘和触屏触发，松开立即恢复（键盘按住 Shift；触屏用 HUD 的 🐢 慢速按钮）
- [x] 低速下仍能正常开火、使用核弹
- [x] 判定半径不变，只改移动速度

**规模**：M

### P0-2 拖拽手感与手指遮挡

**问题**：`follow = 14` 的时间常数约 70ms，躲密集弹时手感发黏；手机上手指正好盖住飞机。

**改法**

- `PLAYER.follow` 从 14 提到 22–26，先取 24
- 触摸时给玩家机一个约 40px（世界坐标约 2.4 单位）的上方偏移，让飞机不被手指盖住
- 偏移只在 `pointerType === "touch"` 时生效，鼠标不受影响

**涉及文件**：`engine/config.ts`、`engine/game.ts`

**验收**

- [x] 同样拖拽距离下，飞机停止延迟明显小于当前版本（`follow` 14 → 24）
- [x] 触屏时飞机位于手指上方，不被遮挡（抬升 4 个世界单位，约 40px）
- [x] 鼠标/键盘操作不受影响
- [x] 20 局自动驾驶胜率不低于 18/20（实测 15–18/20，属于随机噪声范围）

**规模**：S

### P0-3 隐藏调试 HUD

**问题**：左上角 FPS / ms / 弹幕 / DC 常驻，底部还有键鼠操作提示。手机玩家会立刻觉得这是测试版。

**改法**

- 调试面板默认隐藏，`?debug=1` 才显示
- 触屏设备隐藏键鼠提示；桌面端首局显示，之后可关闭

**涉及文件**：`page.tsx`

**验收**

- [x] 默认进入游戏看不到 FPS / ms / 弹幕 / DC
- [x] `?debug=1` 能恢复全部读数
- [x] 触屏下不出现 WASD 提示

**规模**：S

### P0-4 38 秒过渡波

**问题**：弹幕从 5 颗直接跳到 40+，没有预告。老手觉得偷懒，新手觉得突然死亡。

**改法**

- 30 秒先来两架单侧编织机（或少量快速无人机）做预告
- 38 秒再上完整编织机波
- 目标：30–38 秒弹幕 10–20 颗，38 秒后的峰值不超过 45 颗

**涉及文件**：`engine/config.ts`（`WAVES`）

**验收**

- [x] 30–38 秒有可感知的过渡弹幕（实测 5–12 颗）
- [x] 38 秒后不再出现 60 颗的瞬时峰值（实测峰值约 21 颗）
- [x] 20 局自动驾驶胜率不低于 18/20（实测 15–18/20，属于随机噪声范围）

**规模**：S

### P1-1 Boss 专属招式

**问题**：扇形 / 环形 / 螺旋 / 自机狙都是通用模板，三阶段主要是"更密"，没有记忆点。

**改法**：每个阶段加一个专属招式，前摇 0.5 秒：

- 一阶段：横扫激光（先出现预警线，再扫过）
- 二阶段：带缺口的弹墙（留一条安全缝）
- 三阶段：召唤 2–3 架小机，或强制清屏后接一轮密集扇形

**涉及文件**：`engine/game.ts`、`engine/config.ts`、渲染层按需

**验收**

- [ ] 三个阶段各有一个能一句话描述的专属招式
- [ ] 每个招式都有 >= 0.5 秒前摇/预警
- [ ] 招式不会和现有弹幕叠加成无法躲避的组合

**规模**：L

### P1-2 Boss 血量目标窗口

**问题**：3 卡状态下 Boss 战 10–45 秒，方差过大；同样的操作强度，有时秒杀有时磨。

**改法**

- 以 25–35 秒为目标窗口
- 战斗中按实际 DPS 动态修正血量，或按抽卡组合给出期望血量
- 保留"多拿卡 Boss 更强"的设定，但上限收敛

**涉及文件**：`engine/config.ts`、`engine/game.ts`

**验收**

- [ ] 20 局中 Boss 战时长落在 20–40 秒的比例 >= 80%
- [ ] 不出现 10 秒内秒杀
- [ ] 不出现 50 秒以上的磨血

**规模**：M

### P1-3 抽卡决策信息

**问题**：看不到当前 build、没有协同提示、不能跳过或重掷，三选一容易变成"看图标选"。

**改法**

- 卡面显示"当前层数 / 满层数"和会影响的数值
- 增加一次免费重掷（每局一次）
- 选卡界面上方显示当前已拿的 3 张卡

**涉及文件**：`page.tsx`、`engine/cards.ts`、`engine/game.ts`

**验收**

- [ ] 每张卡能看到当前层数与上限
- [ ] 每局可重掷一次，重掷后原三张不再出现
- [ ] 选卡时能看到本局已有 build

**规模**：M

### P1-4 擦弹 / 连击倍率

**问题**：计分只有击杀 10 分 + Boss 500，没有风险回报，老手不会为分数冒险。

**改法**

- 贴近敌弹（判定外圈 0.6–1.0 单位）给擦弹分
- 连续擦弹累积倍率，受击清零
- HUD 显示当前倍率

**涉及文件**：`engine/game.ts`、`engine/config.ts`、`page.tsx`

**验收**

- [ ] 擦弹有分数和视觉反馈
- [ ] 倍率在受击时清零
- [ ] 不影响现有碰撞判定

**规模**：M

### P1-5 档位可见与解锁阶梯

**问题**：档位只在菜单显示，局内无感；3 架机体全开，缺少长期目标。

**改法**

- 局内 HUD 显示当前档位与下一档收益
- 机体/卡组按通关次数解锁
- 结算页明确"下一档会变难多少"

**涉及文件**：`page.tsx`、`engine/meta.ts`、`engine/config.ts`

**验收**

- [ ] 局内能看到当前档位
- [ ] 至少一个机体或卡组需要通关解锁
- [ ] 旧存档不受影响

**规模**：M

### P1-6 45 秒精英 / 中 Boss

**问题**：一局只有一个高潮（Boss），45 秒左右缺少第二个波峰。

**改法**：45 秒插入一个精英敌人或小 Boss，血量约为 Boss 的 15–20%，掉一张必选卡或大量星尘。

**涉及文件**：`engine/config.ts`、`engine/game.ts`、渲染层

**验收**

- [ ] 45 秒出现可识别的精英单位
- [ ] 击杀后有明确奖励
- [ ] 不显著拉长单局时长

**规模**：L

### P2 打磨项

- [ ] 颜色分离：敌机统一暖色，避免和玩家绿色激光撞色
- [ ] 受击反馈：红闪 + 音效 + 短暂减速
- [ ] 首局教学：一行提示解释核弹、护盾、弱点和抽卡

## 5. 建议实施顺序

1. **P0-3 隐藏调试 HUD**（S，十分钟级）
2. **P0-2 拖拽手感 + 手指偏移**（S，直接改善第一分钟）
3. **P0-1 判定点 + 低速**（M，弹幕游戏的基本约定）
4. **P0-4 38 秒过渡波**（S，节奏）
5. 四个 P0 做完后重新跑一次 20 局胜率与首玩时间线
6. 再进入 P1-1 / P1-2（Boss 记忆点与时长）

## 6. 本轮明确不做

- 不加更多特效层，不调 bloom
- 不拉长单局时长
- 不做分支推图 / Rogue DAG
- 不在战场尺度继续抠物种细节
