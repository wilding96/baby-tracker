# 我的反差妹妹：风险选择与生命值系统设计

## 背景与目标

当前「我的反差妹妹」中，`power` / `fame` 两个数值只在第三轮妹妹场景被当作隐藏门槛使用，前面的选择大多只是加减数值，玩家感受不到“选择有后果”。另外，第一轮火灾和第二轮暗杀是固定剧情死亡，用来推进轮回。

本次改动的目标是：

1. 让大多数选择都带有风险感，减少“假选择”。
2. 增加一个可见的、简单的生命值系统，失败时能进入 Game Over。
3. 保留现有“受难—挣扎—反杀”的三周目主线，以及第一轮、第二轮两次固定死亡。
4. 保持轻量、易上手，不新增复杂系统。

## 当前实现摘要

- 状态：`power`、`fame`，初始为 0，范围 0–100。
- 每个选择有 `power`、`fame` 两个增量，部分选项还有 `requiresPower` / `requiresFame` 门槛。
- 记忆系统目前只有一枚「黑手徽记」，用于解锁第三轮董事会的一个额外选项。
- 第一轮 `l1-death` 与第二轮 `l2-death` 是必然死亡，死亡后进入下一周目。

## 目标设计

### 1. 生命值显示

- 移除右上角的 `实力` / `声望` 两个条。
- 改为一条连续的进度条，初始满值，共 5 格。
- 进度条上分布 5 颗爱心作为刻度，爱心会随当前血量点亮或熄灭。
- 扣血和回血时，进度条与爱心一起做平滑过渡动画。

视觉示例（满血）：

```
❤️ ❤️ ❤️ ❤️ ❤️
[████████████████████]
```

### 2. 选择结果

每个选项新增一个结果标记，取值为：

- `safe`：稳妥选择，不扣血。
- `risky`：冲动、冒险、硬刚的选择，扣 1 格。
- `bonus`：少数关键正确选择，回 1 格，但不会超过 5 格。

需要重新过一遍所有场景，确保多数场景中至少存在一个 `risky` 选项。

### 3. Game Over 规则

- 初始血量：5。
- 选择 `risky` 时扣 1 格。
- 若当前血量已经是 0，玩家再次选择 `risky`，触发 Game Over。

边界示例：

```
血量 1 -> 选 risky -> 血量 0（不 Game Over）
血量 0 -> 选 risky -> Game Over
```

- Game Over 是独立失败画面，包含对应剧情文案。
- 失败画面提供两个操作：
  - 回到本周目开头
  - 重新开始

### 4. 结局规则

- 取消 `power` / `fame` 的隐藏门槛。
- 玩家只要活着走到第三轮妹妹场景，就可以选择结局。
- 结局走向由「记忆/证据」与最终选择共同决定。
- 保留现有「黑手徽记」记忆门，前两个周目的 `risky` 选择只影响能否活到结局，不直接决定结局标签。

## 数据模型改动

### 状态

移除：

- `power`
- `fame`

新增：

- `hearts: number`，范围 0–5，初始 5。

### 选项

移除：

- `power` 增量
- `fame` 增量
- `requiresPower`
- `requiresFame`

新增：

- `outcome: "safe" | "risky" | "bonus"`

### 场景

- `l1-death`、`l2-death` 保留 `onLoop: true`，仍作为固定剧情死亡推进轮回。
- 其他场景中的 `choices` 重新标注 `outcome`。

## 涉及文件

- `src/app/game/my-re-life/page.tsx`
- `src/app/game/my-re-life/styles.css`

## 行为流程

1. 游戏初始化时 `hearts = 5`。
2. 玩家在任意场景做出选择。
3. 根据选项的 `outcome` 更新血量并触发动画。
4. 若选择 `risky` 且当前血量为 0，进入 Game Over。
5. 否则继续推进剧情。
6. 第一轮、第二轮末尾仍进入固定死亡，并进入下一周目。
7. 第三轮妹妹场景选择结局。

## 测试要点

- 初始显示 5 格满血。
- `risky` 从 5 扣到 0 的过程正确，动画触发。
- 血量为 0 时选择 `safe` 不触发 Game Over。
- 血量为 0 时选择 `risky` 触发 Game Over。
- `bonus` 在满血时不会超过 5 格。
- 回到本周目开头能恢复该周目开始时的血量状态。
- 重新开始能恢复到初始 5 格。
- 结局选择不再依赖 `power` / `fame`。
