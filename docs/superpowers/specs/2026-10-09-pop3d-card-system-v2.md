# POP3D 卡牌系统 v2 设计（普通 / 炫彩两档）

日期：2026-10-09　参考：海克斯大乱斗的强化分级（普通＝小数值，炫彩＝质变）

**目标**：砍掉不实用的卡，只留 5 个类别；每类分**普通卡（银）**与**炫彩卡（棱彩）**两档；
炫彩卡必须是"改变玩法/看得见"的效果，而不是更大的数字。

---

## 3. 新机制

**护盾**：`shield` 是独立资源（有上限、可回填），受伤**先扣盾**，盾破才掉血；
套上时有一圈"罩上来"的动画（0.35 秒从大到小落到机体上），被击穿时碎裂（短促爆点 + 环状冲击）。
HUD 要在生命条上方多一条护盾条（青色）。

**核弹**：新资源，初始 0 次，只能靠卡获得。释放时：
立刻清空全部敌弹 + 对全场敌人造成 800 伤害 + 白闪 + 冲击波环 + 震屏 + 0.25s 停帧 + 0.3s 慢动作。
触发方式建议：键盘 `B` + HUD 上的核弹按钮（触屏可点）。

**僚机类型**：
- 攻击型：跟随侧后方，独立冷却（主武器冷却 ×1.15），继承机型弹型/属性，伤害 ×0.6（核心升级后 ×0.9）
- 支援型：环绕在玩家身边**不攻击**，每 2 秒 +3 护盾（核心升级后 +6）

## 4. 抽卡规则

- 三选一：**2 普通 + 1 炫彩**；炫彩池抽空后退化为 3 普通
- 炫彩卡**每局唯一**；普通卡按上表上限（满层不再出现，现有 `offerPool` 已保证）
- 炫彩卡在三选一里有独立的棱彩外观（流光描边 + 更亮的图标），一眼可辨

## 5. 需要删除 / 合并的旧卡（影响面）

| 旧卡 | 去向 |
| --- | --- |
| 超频 / 扇形弹 / 贯穿 / 后向炮 | **并入 `wpn`**（按机型给"射速/弹数/贯穿/背射"对应的成长） |
| 追踪弹 / 分裂弹 | **并入 `wpnX`**（机型质变里体现：鱼鳞溅射 / 激光分叉） |
| 环绕护卫弹 | **并入支援型僚机**（视觉与机制复用：环绕在身边的支援机） |
| 属性流 4 张（电/火/冰/精通） | 删除 → 见下面的待定问题 ① |
| 击杀回血 / 背水一战 / 能量回流 / 赏金猎人 / 星尘转化 | 删除（可挪到局外养成） |
